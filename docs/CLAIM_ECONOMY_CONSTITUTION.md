# Claim Economy Constitution

## Purpose

The Claim Economy converts research and operational evidence into reusable
knowledge while preserving uncertainty, disagreement, and provenance.

## Constitutional Separation

1. A producing Claim Factory may draft and support a claim.
2. It may not verify, promote, retract, or erase its own claim.
3. Verification must come from a separately chartered factory.
4. Promotion is a deterministic policy decision over signed artifacts.
5. Consequential domains retain human approval.
6. Contradictions remain visible.
7. Retraction and supersession append lineage; they do not rewrite history.
8. Missing or malformed evidence fails closed.

## Factory Workforce

Factories are staffed organizations. A worker occupies one bounded seat:

| Seat | Responsibility |
| --- | --- |
| Factory foreman | Assigns work and checks required seats |
| Intake steward | Validates the assignment envelope |
| Claim decomposer | Converts compound prose into atomic candidates |
| Evidence binder | Attaches evidence and provenance receipts |
| Source-span verifier | Confirms that cited spans support the statement |
| Contradiction hunter | Searches for counterevidence |
| Confidence calibrator | Applies measured calibration, never vibes |
| Lineage keeper | Connects dependencies, supersession, and retraction |
| Privacy redactor | Prevents protected material from entering public artifacts |
| Independent reproducer | Attempts reproduction in a verifier factory |
| Falsification worker | Tries to disprove the candidate |
| Factory auditor | Checks factory policy and worker independence |
| Retraction steward | Opens append-only correction workflows |
| Proof promoter | Packages approved evidence for a Proof Drop |

No seat receives authority merely because a model claims expertise.

## Artifact Flow

```text
assignment
  -> producer roster admission
  -> proposed claim + producer receipt
  -> immutable verification package
  -> verifier roster admission
  -> support, challenge, or inconclusive report
  -> promotion policy
  -> verified, supported, disputed, or rejected state
  -> append-only registry event
```

## Feedback Loop

Factory failures become University lessons and ToolGym fixtures. Credentials can
expire, be suspended, or be revoked. Strong work history may qualify an agent
for a more demanding role, but never bypasses the next role's practical exam.
